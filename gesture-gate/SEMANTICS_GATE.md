# Semantics and focus gate

This is an additive gate for the accessibility tree and the focus chain. It
does not edit shared CI files, IR, the native ABI, or renderer sources.

Flutter 3.50.0 source anchors (`ab2912035e160d9cad6306df307576da6128ebdb`):

- `packages/flutter/lib/src/semantics/semantics.dart:1719-1805`: every node
  exposes a label, a role and the current state, and the tree is built in
  layout order.
- `packages/flutter/lib/src/widgets/focus_manager.dart:328-341`: the focus
  chain follows the traversable layout order.
- `packages/flutter/lib/src/widgets/focus_traversal.dart:156-171`: traversal
  order is the layout order of the traversable nodes.

## Report

`gesture-semantics-report.json` is written by
`tests/gesture_semantics_report.rs`:

```json
{
  "schema": "opurom.gesture.semantics/1",
  "source": "flutter-3.50.0:ab2912035e160d9cad6306df307576da6128ebdb",
  "clock": "logical",
  "digest": "7f41a3d89c3eb167",
  "metrics": {
    "semantics_nodes": 8,
    "semantics_focusable": 3,
    "semantics_roles": 6,
    "semantics_json_bytes": 653,
    "semantics_state_delta": 2
  }
}
```

- `semantics_nodes`: nodes in the semantic tree, one per IR node.
- `semantics_focusable`: nodes in the focus chain. A hidden node is not
  traversable, because Flutter does not attach hidden semantics to the tree.
- `semantics_roles`: distinct roles in the closed role set.
- `semantics_json_bytes`: size of the canonical semantic projection.
- `semantics_state_delta`: semantic fields that change when the boolean
  state flips, which proves the state reaches the tree.
- `digest`: digest of the semantic JSON. The gate generates the report twice
  and requires both digests to match, so the projection must be reproducible
  across processes.

## Gate rules

1. The report is generated by the Rust fixture, or supplied with `--report`.
2. The counts are bounded rather than frozen: another lane may legitimately
   add a semantic node, but an empty focus chain or an unbounded tree is a
   regression.
3. Without a baseline the verdict is `N/A` (exit `0`): the absolute limits
   were checked, but no regression comparison is possible.
4. With a baseline, no count may exceed `baseline * 2 + 8`.
5. `PASS` exits `0`, `FAIL` exits `1`, usage or IO errors exit `2`.
6. The verdict is printed as `opurom.gesture.semantics.gate/1` JSON.

```sh
# Fresh report, absolute limits only.
node gesture-gate/gesture-semantics-gate.mjs

# Freeze a baseline and compare against it.
node gesture-gate/gesture-semantics-gate.mjs --write-baseline semantics-baseline.json
node gesture-gate/gesture-semantics-gate.mjs --baseline semantics-baseline.json

# Self tests: PASS, N/A and FAIL.
node gesture-gate/gesture-semantics-gate.mjs --self-test pass
node gesture-gate/gesture-semantics-gate.mjs --self-test na
node gesture-gate/gesture-semantics-gate.mjs --self-test fail
```
Targeted fault self tests: `digest_drift`, `state_delta_lost` (each exits 1 when detected).


The joint gate runs this gate as its fourth evidence source and reports
`semantics_gate_status` plus `semantics_machine_report`; the evidence
archiver stores the canonical semantics metrics as `semantics.json`.
