# Nested scroll coordination gate

This is an additive gate for the nested scroll coordinator. It does not edit
shared CI files, IR, the native ABI, or renderer sources.

The coordinator itself lives in `opurom-render/src/scroll_physics.rs` as a
data-only projection: an outer position, a list of inner positions and the
Flutter drag split between them.

Flutter 3.50.0 source anchors (`ab2912035e160d9cad6306df307576da6128ebdb`):

- `packages/flutter/lib/src/widgets/nested_scroll_view.dart:1068-1130`
  (`applyUserOffset`): a drag up removes the inner overscroll first and then
  moves the outer view, a drag down gives the inner positions what they can
  and hands the rest to the outer view.
- `packages/flutter/lib/src/widgets/nested_scroll_view.dart:1262-1313`
  (`applyClampedDragUpdate`): a clamped update never enters an overscroll and
  returns the delta that was not used.
- `packages/flutter/lib/src/widgets/nested_scroll_view.dart:1315-1340`
  (`applyFullDragUpdate`): a full update applies the whole delta and may enter
  an overscroll.
- `packages/flutter/lib/src/widgets/scroll_notification.dart:31-56`: a
  notification carries a depth, zero for the local notification.
- `packages/flutter/lib/src/widgets/notification_listener.dart:92-138`: a
  notification is delivered to the target and to every ancestor until a
  listener consumes it.

## Report

`gesture-nested-report.json` is written by `tests/gesture_nested_report.rs`:

```json
{
  "schema": "opurom.gesture.nested/1",
  "source": "flutter-3.50.0:ab2912035e160d9cad6306df307576da6128ebdb",
  "clock": "logical",
  "metrics": {
    "nested_handoff_steps": 5,
    "nested_outer_consumed_milli": 140000,
    "nested_inner_consumed_milli": 80000,
    "nested_unconsumed_milli": 0,
    "nested_overscroll_px": 40,
    "nested_notification_depth": 2
  }
}
```

- `nested_handoff_steps`: drag updates where the outer view took the drag
  while the inner position was at its edge.
- `nested_outer_consumed_milli` and `nested_inner_consumed_milli`: the pixels
  each side consumed, in thousandths of a logical pixel.
- `nested_unconsumed_milli`: the part of a drag that no position consumed; it
  must stay small, because a silently dropped drag is a defect.
- `nested_overscroll_px`: the largest inner overscroll the sequence reached.
- `nested_notification_depth`: the deepest ancestor a notification reached.

## Gate rules

1. The report is generated by the Rust fixture, or supplied with `--report`.
2. The counts are bounded rather than frozen, so another lane may change the
   fixture without breaking the gate, but an empty handoff or a dropped drag
   is a regression.
3. Without a baseline the verdict is `N/A` (exit `0`).
4. With a baseline, no count may exceed `baseline * 2 + 8`.
5. `PASS` exits `0`, `FAIL` exits `1`, usage or IO errors exit `2`.
6. The verdict is printed as `opurom.gesture.nested.gate/1` JSON.

```sh
# Fresh report, absolute limits only.
node gesture-gate/gesture-nested-gate.mjs

# Freeze a baseline and compare against it.
node gesture-gate/gesture-nested-gate.mjs --write-baseline nested-baseline.json
node gesture-gate/gesture-nested-gate.mjs --baseline nested-baseline.json

# Self tests: PASS, N/A and FAIL.
node gesture-gate/gesture-nested-gate.mjs --self-test pass
node gesture-gate/gesture-nested-gate.mjs --self-test na
node gesture-gate/gesture-nested-gate.mjs --self-test fail
```

The joint gate runs this gate as its fifth evidence source and reports
`nested_gate_status` plus `nested_machine_report`; the evidence archiver
stores the canonical nested metrics as `nested.json`.
