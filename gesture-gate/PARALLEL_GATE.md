# Parallel pointer arena gate

This is an additive gate for the parallel pointer arena engine. It does not
edit shared CI files, IR, the native ABI, or renderer sources.

Flutter 3.50.0 source anchors (`ab2912035e160d9cad6306df307576da6128ebdb`):

- `packages/flutter/lib/src/gestures/arena.dart:117-129`: the arena manager
  keeps one arena per pointer id.
- `packages/flutter/lib/src/gestures/arena.dart:226-292`: accept and reject run
  exactly once per member, and cancel rolls back its own arena.
- `packages/flutter/lib/src/gestures/scale.dart:586-592`: a second pointer on a
  resolved node joins the scale recognizer.
- `packages/flutter/lib/src/gestures/multitap.dart:328-337,355`: a held tap is
  awarded when the double-tap window ends.
- `packages/flutter/lib/src/gestures/binding.dart:407-448`: the down-time hit
  path is cached per pointer id.

## Report

`gesture-parallel-report.json` is written by
`tests/gesture_parallel_report.rs`:

```json
{
  "schema": "opurom.gesture.parallel/1",
  "source": "flutter-3.50.0:ab2912035e160d9cad6306df307576da6128ebdb",
  "clock": "logical",
  "metrics": {
    "parallel_active_arenas": 2,
    "parallel_resolved_arenas": 1,
    "parallel_independent_wins": 1,
    "parallel_replay_stable": 1,
    "parallel_next_deadline_ms": 500
  }
}
```

- `parallel_active_arenas`: the number of pointers that opened an arena.
- `parallel_resolved_arenas`: the primary contest that resolved to a winner.
- `parallel_independent_wins`: the secondary pointer that resolved its own
  contest while the primary was still active.
- `parallel_replay_stable`: the replay repeated the same winner.
- `parallel_next_deadline_ms`: a pending pointer still reports its long-press
  deadline, which is the Flutter `kLongPressTimeout` of 500 ms.

## Gate rules

1. The report is generated by the Rust fixture, or supplied with `--report`.
2. `parallel_replay_stable` must equal `1`. The other counts are bounded
   rather than frozen, so another lane may extend the fixture.
3. Without a baseline the verdict is `N/A` (exit `0`).
4. With a baseline, no count may exceed `baseline * 2 + 8`.
5. `PASS` exits `0`, `FAIL` exits `1`, usage or IO errors exit `2`.
6. The verdict is printed as `opurom.gesture.parallel.gate/1` JSON.

```sh
# Fresh report, absolute limits only.
node gesture-gate/gesture-parallel-gate.mjs

# Freeze a baseline and compare against it.
node gesture-gate/gesture-parallel-gate.mjs --write-baseline parallel-baseline.json
node gesture-gate/gesture-parallel-gate.mjs --baseline parallel-baseline.json

# Self tests: PASS, N/A and FAIL.
node gesture-gate/gesture-parallel-gate.mjs --self-test pass
node gesture-gate/gesture-parallel-gate.mjs --self-test na
node gesture-gate/gesture-parallel-gate.mjs --self-test fail
```

The joint gate runs this gate as its sixth evidence source and reports
`parallel_gate_status` plus `parallel_machine_report`; the evidence archiver
stores the canonical parallel metrics as `parallel.json`.
