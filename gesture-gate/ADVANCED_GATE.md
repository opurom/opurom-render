# Advanced gesture gate

This is an additive gate for the advanced gesture fields: scale rotation and
the drag start behavior. It does not edit shared CI files, IR, the native ABI,
or renderer sources.

Flutter 3.50.0 source anchors (`ab2912035e160d9cad6306df307576da6128ebdb`):

- `packages/flutter/lib/src/gestures/scale.dart:487-509`: the signed rotation
  factor is `angle2 - angle1` from two `atan2` lines.
- `packages/flutter/lib/src/gestures/scale.dart:738-750,772`: the update
  carries scale, focal point and rotation.
- `packages/flutter/lib/src/gestures/recognizer.dart:48-56`:
  `DragStartBehavior.down` anchors the drag at the down point, `start` at the
  arena-win point.
- `packages/flutter/lib/src/gestures/monodrag.dart:103-125`: the win position
  is used by `start`.

## Report

`gesture-advanced-report.json` is written by
`tests/gesture_advanced_report.rs`:

```json
{
  "schema": "opurom.gesture.advanced/1",
  "source": "flutter-3.50.0:ab2912035e160d9cad6306df307576da6128ebdb",
  "clock": "logical",
  "metrics": {
    "rotation_quarter_turn_milli": -1571,
    "rotation_horizontal_milli": 0,
    "drag_down_origin_delta": 20,
    "drag_start_origin_delta": 0,
    "drag_threshold_px": 18
  }
}
```

- `rotation_quarter_turn_milli`: a signed quarter turn in thousandths of a
  radian, bounded to one full turn.
- `rotation_horizontal_milli`: a horizontal move keeps rotation at zero.
- `drag_down_origin_delta`: the first drag delta when the origin is the down
  point; it must be non-zero.
- `drag_start_origin_delta`: the first delta when the origin is the arena-win
  point; it must be zero.
- `drag_threshold_px`: Flutter `kTouchSlop`, fixed at 18.

## Gate rules

1. The report is generated by the Rust fixture, or supplied with `--report`.
2. `rotation_horizontal_milli`, `drag_start_origin_delta` and
   `drag_threshold_px` are exact; the others are bounded.
3. Without a baseline the verdict is `N/A` (exit `0`).
4. With a baseline, no count may exceed `baseline * 2 + 8`.
5. `PASS` exits `0`, `FAIL` exits `1`, usage or IO errors exit `2`.
6. The verdict is printed as `opurom.gesture.advanced.gate/1` JSON.

```sh
# Fresh report, absolute limits only.
node gesture-gate/gesture-advanced-gate.mjs

# Freeze a baseline and compare against it.
node gesture-gate/gesture-advanced-gate.mjs --write-baseline advanced-baseline.json
node gesture-gate/gesture-advanced-gate.mjs --baseline advanced-baseline.json

# Self tests: PASS, N/A and FAIL.
node gesture-gate/gesture-advanced-gate.mjs --self-test pass
node gesture-gate/gesture-advanced-gate.mjs --self-test na
node gesture-gate/gesture-advanced-gate.mjs --self-test fail
```

The joint gate runs this gate as its seventh evidence source and reports
`advanced_gate_status` plus `advanced_machine_report`; the evidence archiver
stores the canonical advanced metrics as `advanced.json`.
